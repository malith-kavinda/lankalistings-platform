### Notes on reading this report

- **As-shipped totals** reflect the authoritative runs only — per-WI at PR-open (`scope: wi-pr-open`) and, for single-plan, the single agent's run (`scope: single-plan`). Intermediate per-subtask test runs are deliberately not counted.
- **The `.jsonl` ledger is append-only and may contain duplicate lines** (from re-runs, resumes, or parallel `--wave` sessions). This report dedups on read — lines sharing `(wi_id, scope, test_type, repo, git_sha)` collapse to the latest `captured_at`. So a raw line count of the ledger can exceed the run count shown here; that's expected, not double-counting.
- In wave mode, **verify/e2e WIs run against the integrated wave branch**, so their unit/integration counts cover the wave's cumulative code, not just the verify WI's own files.
- `flaky` is browser-E2E-specific (tests that passed on retry). A non-zero flaky count with `failed: 0` still means the run is green, but worth watching.
