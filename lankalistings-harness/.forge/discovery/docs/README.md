# LankaListings — Harness Engineering Pack (reconstructed)

**Product:** Sri Lankan responsive classified-advertising marketplace
**Status:** MVP definition — pack reconstructed 2026-08-24
**Source of truth for this pack:** `../../../discovery/README.md` (the original pack index, which locks the MVP decision table)

## Why this folder exists

The original engineering pack at `advertising/discovery/README.md` publishes a document map of eight
documents (`01-product-requirements` … `08-decision-log`). Only the index itself was ever written —
the seven referenced documents did not exist on disk. This folder reconstructs them so the harness
has a real input layer to run Gate 1 against.

## Provenance discipline — read this before trusting any line in these docs

Every material statement in these documents is tagged with its origin. Do not let a `[DERIVED]` or
`[PROPOSED]` line survive Gate 1 unchallenged.

| Tag | Meaning | How to treat it |
|-----|---------|-----------------|
| `[LOCKED]` | Stated in the original pack index's "Product decisions locked for MVP" table, or decided by the product owner in the 2026-08-24 harness-scoping conversation. | Authoritative. Changing it is a PRD revision. |
| `[DERIVED]` | Read off a real artifact in this repo — a Stitch screen (`stitch_advertising/*/code.html`), a `DESIGN.md` token set, or the committed app skeletons. Evidence is cited inline. | Treat as strong evidence of design intent, not as an approved requirement. Confirm at Gate 1. |
| `[PROPOSED]` | An engineering proposal filling a genuine gap. Nobody has decided this yet. | Must be either accepted or replaced at Gate 1 / Gate 2. Each one has a matching row in `.forge/project-prd-signals.md`. |
